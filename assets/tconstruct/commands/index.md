# Tinkers' Construct Commands

The commands Tinkers' Construct adds. Only the ones your permission level allows are listed; the server checks it again when you run one. Commands that change a tool act on the main-hand tool of each target. Ids may leave out `tconstruct:` (`haste` is `tconstruct:haste`). Open this menu with `/tconstruct`.

*Levels: 0 everyone, 1 moderators, 2 game masters, 3 admins, 4 owners.*
