# slots

**Usage:** `/tconstruct slots <targets> add|set <slot_type> [count]`

Changes the free modifier slots of the held tool. `add` gives (or with a negative count takes) that many slots, one by default; `set` makes the free count exactly that number. Slot types: `upgrades`, `abilities`, `defense`, `souls`.
