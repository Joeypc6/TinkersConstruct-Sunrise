# modifiers

**Usage:** `/tconstruct modifiers <targets> add|remove <modifier> [level]`

Adds a modifier to the held tool (one level unless you give more), or removes it (every level unless you give a number). It uses no slots, but the tool must still be valid afterwards: a change that leaves too few slots or breaks a modifier's requirements is refused.
