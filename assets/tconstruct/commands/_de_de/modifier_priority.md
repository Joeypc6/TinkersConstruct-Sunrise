# report modifier_priority

**Verwendung:** `/tconstruct report modifier_priority`

Schreibt jeden Modifikator mit seiner Priorität ins Spiel-Log, die höchste zuerst: Modifikatoren mit höherer Priorität wirken zuerst auf ein Werkzeug.
