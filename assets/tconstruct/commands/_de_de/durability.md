# durability

**Verwendung:** `/tconstruct durability <targets> add|set <amount>`

Repariert oder beschädigt das gehaltene Werkzeug. `add` stellt so viel Haltbarkeit wieder her (eine negative Menge beschädigt es); `set` lässt genau so viel Haltbarkeit übrig. Nur Werkzeuge mit Haltbarkeit zählen.
