# Tinkers'-Construct-Befehle

Die Befehle von Tinkers' Construct. Es werden nur die gezeigt, die deine Berechtigungsstufe erlaubt; der Server prüft sie beim Ausführen erneut. Befehle, die ein Werkzeug ändern, wirken auf das Werkzeug in der Haupthand jedes Ziels. IDs dürfen `tconstruct:` weglassen (`haste` ist `tconstruct:haste`). Öffne dieses Menü mit `/tconstruct`.

<SubPages />

*Stufen: 0 alle, 1 Moderatoren, 2 Spielleiter, 3 Admins, 4 Besitzer.*
