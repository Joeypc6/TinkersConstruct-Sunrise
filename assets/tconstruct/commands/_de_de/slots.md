# slots

**Verwendung:** `/tconstruct slots <targets> add|set <slot_type> [count]`

Ändert die freien Modifikatorplätze des gehaltenen Werkzeugs. `add` gibt (oder nimmt mit negativer Zahl) so viele Plätze, standardmäßig einen; `set` setzt die freie Anzahl genau auf diese Zahl. Platztypen: `upgrades`, `abilities`, `defense`, `souls`.
