# Réservoirs Calcinés

Les réservoirs sont utiles pour stocker les fluides ou carburants en fusion. Si tu veux faire fondre des métaux dans ta fonderie, il t’en faudra un ! Les réservoirs peuvent aussi être remplis depuis la fonderie si tu veux stocker des matériaux pour plus tard.

Les réservoirs ne peuvent pas être utilisés pour le sol de la fonderie.
