# Réparation

Pour réparer les outils, place simplement l’outil dans l’Atelier du Bricoleur ou l’Enclume du Bricoleur avec le matériau de la tête. Sinon, tu peux utiliser des kits de réparation, qui fonctionnent aussi bien dans une table de craft qu’en faisant un clic droit directement sur l’outil !
