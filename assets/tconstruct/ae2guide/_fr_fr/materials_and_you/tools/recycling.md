# Recycler les Outils

![](tconstruct:book/recycling.png)

Si tu changes d’avis sur un outil, tu peux toujours le démonter dans le constructeur de pièces pour récupérer l’une de ses parties. Il est possible d’en récupérer une deuxième, avec plus de chances si l’outil est réparé. Les dagues doivent être empilées par 2 pour pouvoir être recyclées.
