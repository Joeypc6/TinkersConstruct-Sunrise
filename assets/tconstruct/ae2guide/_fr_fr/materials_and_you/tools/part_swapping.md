# Échange de Pièces

![](tconstruct:book/part_swapping.png)

Tu as déjà souhaité pouvoir corriger une erreur passée ? Heureusement, c’est possible avec les outils. Si tu veux changer le matériau d’une des pièces, place l’outil avec la nouvelle pièce souhaitée dans l’atelier du bricoleur. Pour les outils ayant plusieurs fois la même pièce, essaie plusieurs emplacements pour remplacer la bonne. Pour les armures, tu peux souvent échanger des pièces en utilisant une table de coulée.
