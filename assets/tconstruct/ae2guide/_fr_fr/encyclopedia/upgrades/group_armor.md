# Améliorations d'Armure

Les améliorations d'armure sont généralement efficaces sur un seul type d’armure ou conçues pour fonctionner en contre-attaque. Si elles sont applicables à plusieurs pièces, leurs effets interagissent souvent entre eux.

Les modificateurs de contre-attaque pour les boucliers ne fonctionnent que pendant le blocage, mais sont alors deux fois plus efficaces. Les autres modificateurs de bouclier fonctionnent passivement.
