# Extraer Modificadores

<Recipe id="tconstruct:tools/modifiers/worktable/extract/modifier" />

¿Quieres mover ese modificador a otra herramienta en lugar de simplemente borrarlo? Solo usa una esponja mojada y un cristal: skyslime para mejoras, earthslime para defensa, ícor para habilidades, amatista para los 'slotless' o enderslime para cualquier cosa. El cristal se llenará con la esencia del modificador y podrás aplicarlo en otra herramienta.
