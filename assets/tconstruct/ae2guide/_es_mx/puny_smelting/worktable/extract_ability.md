# Extraer Habilidad

<Recipe id="tconstruct:tools/modifiers/worktable/extract/ability" />

Extraer modificadores de habilidad de herramientas encantadas es un proceso bastante costoso; requiere no solo cristales de ícor, sino también un diamante para ayudar en el proceso. Incluso con el poder del ícor, la herramienta se perderá para siempre.
