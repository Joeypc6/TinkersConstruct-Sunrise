# Remover Modificadores

<Recipe id="tconstruct:tools/modifiers/worktable/remove_modifier_sponge" />

A medida que encuentras nuevos materiales, podrías decidir que un modificador ya no es suficiente. Todo lo que tienes que hacer para quitarlo es tallarlo con una esponja mojada. ¿No tienes esponjas? Intenta entonces con un poco de veneno de araña. Remover el modificador te devuelve sus ranuras, pero el material que usaste para aplicarlo se perderá para siempre. Eso sí, puedes volver a usar la esponja.
