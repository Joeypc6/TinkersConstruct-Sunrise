# Herramientas de Daño

![](tconstruct:book/damage_tools.png)

¿Alguna vez has pensado: "Ojalá pudiera romper mi herramienta más rápido"? Solo échale un poco de magma para quitarle algo de durabilidad, o usa veneno para un daño mayor. ¿Aún no es suficiente? Bañala en lava o sangre ardiente para destruirla de verdad.
