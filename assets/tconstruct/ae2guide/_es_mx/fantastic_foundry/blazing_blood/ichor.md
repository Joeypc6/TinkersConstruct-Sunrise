# Ícor

<ItemImage id="tconstruct:ichor_slime_ball" scale="2" />

Puedes obtener sangre ardiente fundiendo ícor, aunque esto es menos ideal, ya que primero necesitas un combustible más caliente para lograr fundirlo. En última instancia, supone una ganancia neta, por lo que es una buena opción para aumentar tus reservas una vez que consigas sangre ardiente de otra fuente.
