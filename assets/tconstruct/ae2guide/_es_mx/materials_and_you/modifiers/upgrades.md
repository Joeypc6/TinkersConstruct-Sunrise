# Mejoras

<ItemImage id="tconstruct:creative_slot" scale="2" />

Las mejoras son optimizaciones para herramientas. Se realizan aplicando un objeto para transferir sus cualidades, como el redstone, que aumenta la velocidad de minado.La mayoría de herramientas inician con 3 ranuras de mejora, aunque puedes conseguir más mediante otros modificadores.

Consulta 'Fundición insignificante' de Thruul M'Gon o la Enciclopedia de Tinkering para ver la lista completa de mejoras.
