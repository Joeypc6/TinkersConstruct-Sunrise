# Habilidades

<ItemImage id="tconstruct:creative_slot" scale="2" />

Las habilidades son modificadores que cambian drásticamente la herramienta, como 'sedoso' para obtener bloques intactos o 'autofundición' para procesar minerales al minar.

Suelen tener una sola ranura inicial y admiten máximo 2 más. Elige con sabiduría.

Consulta 'Fundición poderosa' o la Enciclopedia de Tinkering para ver la lista completa.
