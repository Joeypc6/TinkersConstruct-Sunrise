# Reciclaje de herramientas

![](tconstruct:book/recycling.png)

¿Cambiaste de opinión sobre una herramienta? Puedes usar algo de veneno para desmontarla en el constructor de piezas y rescatar una de sus partes. Existe la posibilidad de recuperar una segunda pieza, con mayor probabilidad si la herramienta está reparada. Las dagas requieren apilarse de a 2 para poder ser recicladas.
