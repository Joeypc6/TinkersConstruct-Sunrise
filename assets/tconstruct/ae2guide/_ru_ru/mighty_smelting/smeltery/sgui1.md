# Графический интерфейс плавильни

<Recipe id="tconstruct:smeltery/melting/metal/iron/ore_singular" />

1: Размещайте предметы для плавки в этих слотах. Размер плавильни определяет кол-во слотов.

2: Здесь отображаются расплавленные металлы. Вы можете щёлкнуть по жидкости, чтобы выбрать её для переливания. При наведении курсора на пустое место отобразится ёмкость плавильни.

3: Здесь вы можете увидеть ваше топливо. При наведении курсора отобразится точное кол-во и тип.

Как во 2, так и в 3, при щелчке [ЛКМ] на жидкостном предмете будет предпринята попытка заполнить его из резервуара, в то время как при щелчке [ПКМ] будет предпринята попытка перелить предмет в резервуар.

4: Этот слот позволяет быстро заполнить или вылить предмет в основной резервуар, действуя так же, как щелчок по сливу с предметом. 5 позволяет ограничить это действие только заполнением или только сливом. После взаимодействия результат будет изменён на 6.
