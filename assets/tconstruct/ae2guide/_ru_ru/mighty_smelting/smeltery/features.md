- Даёт +3 кусочка или +1 драгоценный камень за руду (по умолчанию).
- Возможности массового плавления.
- Может содержать несколько металлов.
- Расширяемая ёмкость.
- Способен смешивать.
- Эффективность потребления топлива зависит от размера.
- Способен плавить сущностей для получения ценных материалов.
- Идеально подходит для плавления большого кол-ва материалов одновременно.
