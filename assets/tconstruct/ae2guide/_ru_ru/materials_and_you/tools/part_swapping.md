# Замена деталей

![](tconstruct:book/part_swapping.png)

Вы когда-нибудь мечтали исправить прошлую ошибку? К счастью, это можно сделать с помощью инструментов. Если вы хотите заменить материал одной из деталей, поместите инструмент вместе с новой деталью в литейную станцию. Для инструментов с несколькими одинаковыми деталями, попробуйте использовать несколько разных слотов, чтобы заменить нужную.
