# Улучшения брони

Улучшения брони обычно эффективны для одного типа брони или предназначены для использования в контратаках. Если они применимы к нескольким предметам, их эффекты обычно взаимодействуют каким-либо образом.

Модификаторы контратаки щитом работают только во время блокирования, но в остальное время вдвое эффективнее. Другие модификаторы щита работают пассивно.
