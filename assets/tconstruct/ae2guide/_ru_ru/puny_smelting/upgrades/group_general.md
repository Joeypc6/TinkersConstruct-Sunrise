# Общие улучшения

Улучшения — это модификации, добавляемые к инструментам с помощью рецептов улучшений. Каждый инструмент изначально имеет ограниченное кол-во слотов для улучшений, хотя их кол-во можно увеличить несколькими способами.

Общие улучшения хорошо работают на любом инструменте! Эти улучшения повысят эффективность вашего инструмента в целом, увеличив его урон, скорость добычи, прочность и многое другое!
