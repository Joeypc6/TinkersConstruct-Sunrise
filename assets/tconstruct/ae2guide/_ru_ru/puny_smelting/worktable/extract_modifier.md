# Извлечение модификаторов

<Recipe id="tconstruct:tools/modifiers/worktable/extract/modifier" />

Хотите перенести этот модификатор на другой инструмент, а не удалять его? Просто используйте мокрую губку и кристалл: небесный слизневый для улучшений, земной слизневый для обороны, ихор для умений, аметист для безслотовых или эндер-слизневый для чего угодно. Кристалл будет заполнен эссенцией модификатора, которую можно будет применить к другому инструменту.
