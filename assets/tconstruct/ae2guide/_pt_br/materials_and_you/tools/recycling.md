# Reciclagem de Ferramentas

![](tconstruct:book/recycling.png)

Se você mudar de ideia sobre uma ferramenta, sempre pode desmontá-la no montador de peças para recuperar uma das peças da ferramenta. Você pode potencialmente recuperar uma segunda peça, com uma chance maior em ferramentas reparadas. Adagas requerem até 2 empilhamento para serem recicladas.
