# Remover Modificadores

<Recipe id="tconstruct:tools/modifiers/worktable/remove_modifier_sponge" />

Eu descobri que é possível remover modificadores das ferramentas usando uma esponja molhada. Se você não tiver uma à mão, veneno de aranha também é eficaz. Remover o modificador me devolve espaço para novos, mas infelizmente os itens usados para aplicá-lo são perdidos. Pelo menos dá pra reutilizar a esponja.
