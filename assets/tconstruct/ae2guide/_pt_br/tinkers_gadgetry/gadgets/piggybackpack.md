# Mochila de Porco

![](tconstruct:book/piggybackpack.png)

Usar uma mochila de porco em uma criatura permite que você a carregue nas costas, perfeito para quando seu porco se cansa em longas viagens. Ela também é útil para jogar monstros dentro da fundição. Já consegui usar até 3 mochilas de porco ao mesmo tempo, embora seja difícil andar com tantos passageiros.
